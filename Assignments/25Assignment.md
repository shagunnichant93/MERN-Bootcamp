# 🧠 MCQs

### 1. Which brackets are used to create an Object?

a) `[]`
b) `{}`
c) `()`
d) `<>`

### 2. Which of the following is an Object?

a)

```javascript
let fruits = ["Apple", "Mango"];
```

b)

```javascript
let student = {
    name: "Rahul",
    age: 25
};
```

c)

```javascript
let age = 25;
```

d)

```javascript
let name = "Rahul";
```

### 3. In this Object, what is `name`?

let student = {
    name: "Rahul"
};
```

a) Value

    age: 25
};
```

b) `age`
c) `25`
